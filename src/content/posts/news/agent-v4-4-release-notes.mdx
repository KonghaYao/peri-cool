## 未进入 agent tag 的部分

1. `#305` OpenUI 组件库抽取与流式渲染（`73447b864`，2026-10-29），属于 `sdk-v0.3.0`，没有进入任何 `agent-v4*` tag。
2. `#306` 遥测 metric 事件挂到 turn root span（`72748ecc8`）。
3. `#312` `claude-sonnet-5-5` adaptive thinking（`283d12db4`）。
4. 文档删减与 skills 索引导航整理（`74ab29c14`、`421d653bd`），不属于产品行为。

## 阶段位置

1. 4.4 仍在第二段「单机服务化」；本版把 SDK、`peri-cf`、模型登录与 MCP 订阅推到服务化入口。
2. 4.4 不是第二段的完成点：Cloudflare 托管部署、跨实例接管与真实云端验收仍未完成。

## 未完成项与证据边界

1. Cloudflare 托管部署、跨实例接管、真实 Turso 凭证回环未验收。
2. WASM 场景下文件工具需要外部 MCP 提供。
3. npm 注册表上 `@peri-code/sdk` 0.3.0 的实际可用性未验证；`sdk-v0.3.0` 只证明仓库打标与 workflow 会发布。
4. tag 日期不是发布日；没有 GitHub Release 与六平台制品构建结果。

## 升级注意

1. `#294` 带破坏性标记，SDK 初始化参数需要按当前接口调整；仓库没有提供自动迁移脚本。
2. ChatGPT 计划登录是新增的一种认证模式，与 API key 模式并列。
3. per-session MCP 订阅通过 `_meta["peri.subscriptions"]` 传递；ACP 类型服务器不支持订阅。
