这份项目更新覆盖 2026-08-02 至 2026-08-12 的仓库证据窗口。窗口内仓库从 `agent-v3.0.0` 标记推进到 `agent-v3.6.5` 标记，这些日期表示 Git tag 的创建时间，不等同于安装制品对公众可用的发布日期。

## 新增 子代理可以恢复旧线程

长任务现在可以让同一个子代理继续已有上下文，而不是每次从空白状态重新派发。后续修订让恢复失败不再干扰新建子代理。具体可用性仍取决于线程是否存在，以及当前会话能否访问对应资源。

验证依据是 8 月 9 日与 10 日合入的子代理恢复提交。使用方式见[子代理](/peri-cool/docs/features/parallel-work/)。

## 新增 后台命令输出可持续查看

后台 shell 返回内容增加进程标识、终止提示和输出查看方式，运行输出同时写入日志文件。长命令不必把全部结果挤进一条工具消息，Agent 也能在后续步骤继续读取进展。

这项变化不保证后台命令不会挂起。运行测试、构建或服务时，仍应给出超时、终止条件和预期完成信号。

## 变更 搜索与文件遍历增加边界

大仓库中的文本搜索增加线程上限和预算停止策略，文件遍历也会收窄扫描根并支持取消。变化目标是更早停止无效遍历，同时保留截断后的可操作结果。

用户不需要修改提示词语法。遇到结果被截断时，应缩小目录、文件类型或搜索模式，而不是反复执行同一个宽搜索。相关研究见[工具 token 消耗](/peri-cool/posts/research/tool-token-consumption/)。

## 新增 会话列表支持删除

TUI 历史面板现在可以删除会话。协议与存储路径随后补齐边界清理，避免只删持久记录却残留运行状态。

删除属于不可恢复操作。执行前确认目标会话，并按[会话管理](/peri-cool/docs/guides/sessions/)备份需要保留的记录。

## 新增 MCP 状态进入会话

首个 turn 会把 MCP 连接概览注入模型上下文，运行期间的上线、下线与失败变化会在 TUI 中形成通知。OAuth 授权流程增加了按钮驱动的交互和手动后备入口。

`/mcp` 仍然以状态查看和 OAuth 入口为主，不是完整配置编辑器。修改 MCP 配置后需要按[MCP 指南](/peri-cool/docs/features/mcp/)重新启动 Peri。

## 修复 后台子代理文本不再混入主回复

后台子代理流式文本曾进入主 agent 的可见回复，并可能把主界面 loading 状态重新拉起。8 月 12 日的 TUI 修复隔离了后台文本与主回复，同时调整运行状态聚合。

这项修复处理的是显示与状态路由，不改变子代理的任务内容。若仍看到文本归属异常，应保留会话状态、任务类型和复现步骤，不要只截取最后一条消息。

## 修复 安装后当前窗口的路径提示

macOS 与 Linux 安装脚本调整了安装后的 PATH 处理，让当前窗口更容易直接找到 `peri`。安装脚本本身仍不会运行 `peri --version`，也不会验证下载制品的 checksum。

更新或重装前请阅读[安装指南](/peri-cool/docs/get-started/installation/)，安全要求较高时先检查脚本与制品来源。已经能正常运行 Peri 的用户无需因为这项提示变化重新安装。

## 证据口径

- `agent-v3.0.0` 至 `agent-v3.6.5` 只作为仓库版本标记窗口。
- 新增、修复与变更来自窗口内主仓库提交及当前代码。
- 这份记录没有核验 GitHub Release、包注册表或安装渠道的发布时间，因此不把 tag 日期写成产品发布日期。

回到 8 月 2 日至 12 日这个证据窗口，用户可见变化集中在长任务续接、后台输出、搜索边界、会话管理和 MCP 状态。需要操作的地方只有两类。删除会话前先备份，修改 MCP 配置后重启 Peri；其余条目不要求用户额外操作，具体可用性以安装渠道中的实际制品为准。
