## 阶段位置

1. 仍在第二段「单机服务化」；本版把内置 MCP 启动收口到一个二进制，并给多条热路径加上界。
2. 单二进制启动不等于工具环境独立驻留；托管部署、跨实例接管与真实云端验收仍未完成。

## 未完成项与证据边界

1. 托管部署、跨实例接管、真实 Turso 凭证回环未验收。
2. `#280` 的 workflow 以 slot 模式启动；需要 ACP 绑定运行时的调用会返回明确的未绑定错误，不会自动恢复。
3. 有界化修复只证明代码路径有界，没有统一的性能对照数据；本页不写吞吐或延迟提升。
4. tag 日期不是发布日；没有 GitHub Release、制品构建结果与 npm 状态。

## 升级注意

1. 旧的 `peri-mcp-workspace` 二进制不存在；改用 `peri mcp-start workspace`。
2. `--use-proxy` 使用 `GITHUB_PROXY` 与 `GITHUB_API_PROXY`；不带参数时保持直连。
3. Read 对超长单行的提示改变；依赖旧提示文本的脚本需要检查。
