## 阶段位置

1. 仍在第二段「单机服务化」；本版处理异步结果、长会话驻留与 MCP 生命周期。
2. 不把本版写成服务化完成；托管部署与跨实例接管仍未验收。

## 未完成项与证据边界

1. 异步结果邮箱的 resume 是显式的；失败或 Stop 之后不自动恢复。
2. MCP 生命周期控制依赖 ACP 客户端支持；未协商的客户端没有入口。
3. `#268` 的修复针对容器重启后的 inode 变化；不覆盖其他会话恢复失败原因。
4. tag 日期不是发布日；没有 GitHub Release、制品构建结果与 npm 状态。

## 升级注意

1. `/tasks` 增加状态列；失败后需要显式 resume。
2. MCP 可以在会话内重启与关闭；需要 TUI 或支持该能力的 ACP 客户端。
3. 长会话窗口 v2 会在旧数据上回填派生索引；仓库没有给出回填耗时数据。
