## 按 patch 看

### 4.0.0（10-11 09:17，版本线基线）

1. 指向 `merge/v4-to-main` 的合并提交（`#179`）。
2. 相对第一父只增加 11 个提交，但这 11 个提交覆盖工具、存储与界面的大批量改动，不能把 11 当作改动量。

### 4.0.1（10-11 16:22，11 个提交）

1. 【新增】TUI MCP 面板打通授权与详情链路，透传连接元信息与失败摘要。
2. 【新增】fork 子代理启动前增加上下文门：使用率超过 75% 拒绝并引导非 fork 子代理。
3. 【修复】dynamic MCP HTTP 连接在 handle 记录配置 URL，详情不再空占位符。
4. 【修复】SandboxWrite 解析沙箱内裸相对路径；tag 版本注入后同步 `Cargo.lock`。

### 4.0.2（10-11 23:39，7 个提交）

1. 【新增】Workflow 编排改为内置 MCP 实例（`#181`）。
2. 【修复】TUI 面板提示与实际动作对齐，覆盖 agent、hooks、plugin 与 Tasks 面板。

### 4.0.3（10-12 17:59，15 个提交）

1. 【新增】TUI 退出后打印会话恢复提示。
2. 【修复】删除 Compact 摘要请求的窗口前置拦截；摘要未完成时在有界预算内恢复，耗尽才终止本轮。
3. 【修复】`print` 模式接受 `--max-turns`；keepgoing 空 Prompt 恢复入队。
4. 【修复】删除遗留 MCP panel pool，消除无归属 `mcp.error` 孤立 trace。

### 4.0.4（10-13 17:54，6 个提交）

1. 【修复】子代理嵌套同步交接能够结算，并在交接时保留待处理任务结果。
2. 【新增】Langfuse 遥测 spool 合入（`#189`），上报不阻塞业务等待；状态为待验收。

### 4.0.5（10-14 14:11，6 个提交）

1. 【新增】MCP Apps canonical 调用契约与附件模型（`#192`）。

3. 【修复】无绑定历史会话按当前观测重建归属（`#218`）；submodule 检出目录按证据不足跳过 worktree 成员核对（`#216`）。

### 4.0.6（10-14 17:18，3 个提交）

## 在项目阶段中的位置

1. 根 `CLAUDE.md` 把项目分为三段：单机本地闭环已完成；单机服务化未完成；集群化与 Serverless 化未完成。
2. 4.0 的改动集中在第二段：工具环境搬进内置 MCP 实例，存储归属细分到机器、工作区、会话，执行恢复从宿主剥离。这个对应关系是本页的归纳，仓库没有为版本线标注阶段名。
3. 4.0 没有完成单机服务化。它立起了边界，把托管部署、跨实例接管与真实云端验收留在后续版本。

## 未完成项与证据边界

1. 托管部署与跨实例接管未验收；WASM 场景下文件工具需要外部 MCP 提供。
2. 遥测 spool 的状态停在「已实施，待用户验收」；本页没有把它写成已验收。
3. `#221` 的 4 项遗留不在本版范围（4.1.0 才进入 tag）；本页不把 4.0 写成上下文所有权已收口。
4. 仓库没有 GitHub Release 发布时间、六平台制品构建结果与 npm 注册表状态；本页只写 tag 与提交。

## 升级注意

1. **会话库会迁移**：升级到 4.x 会走一次单条迁移；仓库没有给出备份提示，升级前请自行备份会话库。
2. **恢复语义收窄**：重启后能加载历史并续聊，但不恢复旧执行。
3. **LSP 能力消失**：不是改名，是整块删除，原有 LSP 工具调用不再存在。
4. **工具名总体不变**：七个文件与终端工具仍是原名；system MCP 工具不再带前缀，重名按先到者生效并告警。
5. **环境变量变化**：`PERI_WRITE_DRAFT` 移除；模型选择改为 provider 与档位成对给出。
