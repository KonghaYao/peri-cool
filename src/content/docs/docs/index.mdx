Peri 的主要产品界面是 TUI。第一次使用不需要先理解配置文件，也不需要手写环境变量。安装后进入一个可回滚的项目目录，启动 Peri，跟着屏幕完成设置即可。

## 第一次使用

1. [安装 Peri](/peri-cool/docs/get-started/installation/)：安装终端程序并确认 `peri --version` 可运行。
2. [在 TUI 中快速上手](/peri-cool/docs/get-started/quickstart/)：启动界面、完成设置、选择模型并提交第一个任务。
3. [认识 TUI](/peri-cool/docs/guides/tui-navigation/)：理解消息区、输入区、状态栏和常用面板。

## 在 TUI 里完成日常操作

- [连接模型服务](/peri-cool/docs/guides/providers/)：首次向导、`/login` Provider 管理和 `/model` 模型选择。
- [会话管理](/peri-cool/docs/guides/sessions/)：新建、继续、恢复、压缩或回退会话。
- [权限系统](/peri-cool/docs/features/permissions/)：理解审批模式，以及它与系统沙箱的区别。
- [图片输入](/peri-cool/docs/features/image-input/)：把截图或本地图片交给 Peri。
- [MCP 服务器](/peri-cool/docs/features/mcp/)：查看外部工具连接状态。
