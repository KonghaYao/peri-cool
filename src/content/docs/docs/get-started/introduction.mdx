Peri 是一个运行在终端里的 AI 编码助手。启动后，你面对的是一套完整 TUI，而不是需要自己拼装的命令管道。任务、工具调用、审批、会话和模型状态都在同一个界面里呈现。

## 打开后会看到什么

Peri TUI 有三个始终可见的区域：

- **消息区** 展示你的任务、Peri 的回复、工具执行和系统提示。
- **输入区** 接收自然语言任务，也用于打开 `/login`、`/model`、`/threads` 等面板。
- **状态栏** 显示权限模式、当前目录、模型档位和后台任务摘要。

首次没有完整 Provider 配置时，界面会先出现设置向导。向导完成后重启 Peri，再从消息区开始工作。

## 一次可靠任务是什么样

不要只给一句模糊目标。更可靠的输入同时包含范围、限制和完成条件：

```text
检查登录失败时的错误处理。先复现问题，只修改 auth 模块；
补回归测试并运行最小测试集。不要改公开 API。
```

执行中，Peri 会在消息区显示读取、搜索、编辑与测试。任务结束时，应能回答三件事：改了什么、怎样验证、还有什么没有验证。

## 模型与 Provider 也在界面里管理

- 首次设置由屏幕向导引导。
- 输入 `/login` 管理 Provider、地址、密钥和模型映射。
- 输入 `/model` 选择模型档位并调整当前配置。

这些操作的完整步骤见[连接模型服务](/peri-cool/docs/guides/providers/)。手动编辑 Settings 只用于自动化、审计或界面不可用时的恢复。

<Aside type="caution" title="审批不是系统沙箱">
  Peri 的权限模式决定工具调用是否需要确认，不等于容器、虚拟机或操作系统隔离。当前无参数启动默认进入 Bypass；第一次在真实仓库使用时，建议运行 <code>peri --permission-mode default</code>，并保持工作区可以回滚。
</Aside>
