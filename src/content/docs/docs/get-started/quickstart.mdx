本页只走 Peri 的主产品路径。你不需要先编辑 JSON 或导出环境变量。

## 1. 在测试仓库启动

安装完成后，进入一个有版本控制、可以回滚的测试仓库：

```bash
cd /path/to/a/test-repository
peri -a
```

`-a` 以 Default 权限模式启动，敏感工具会请求确认。无参数 `peri` 当前默认使用 Bypass，会自动批准工具调用。

## 2. 按屏幕完成首次设置

当配置列表为空且无法取得 Provider，或现有条目缺少必要的名称或凭据时，Peri 会打开设置向导。已有配置时可能直接进入主界面。

向导依次让你：

1. 选择界面语言。
2. 选择手动连接模型服务，或从 Claude Code 配置迁移。
3. 选择 Provider，填写服务地址、API key 和四个模型档位。
4. 确认并保存。

向导里的连通性检查只能提供有限的网络探测，不能证明 API key、模型调用或 TLS 可用。完成界面也不是配置有效的证明。

<Aside type="caution" title="完成向导后重启">
  当前向导把配置写入磁盘，但不会更新正在运行的 ACP 会话。完成后退出 Peri，再次运行 <code>peri -a</code>。不要依赖 <code>/setup</code> 重置向导，它可能重新显示之前的状态。
</Aside>

## 3. 在 TUI 中检查模型

重启后，在输入区依次打开两个面板：

```text
/login
/model
```

`/login` 用于查看、新建或编辑 Provider。`/model` 左侧列出 fable、opus、sonnet、haiku 四档；上下移动会立即切换档位。进入右侧后，左右键修改 Provider、模型或 effort 等字段，修改会立即保存并推送当前会话。

面板显示的是本地配置，不是从远端服务拉取的模型目录。最终验证方式仍是发送一个最小请求。

## 4. 提交第一个只读任务

先让 Peri 只读探索，不修改文件：

```text
解释这个项目的测试入口。不要修改文件；
列出你实际读取的配置文件，并给出建议运行的最小测试命令。
```

按 Enter 提交。运行时可以在消息区看到读取和搜索过程；如果触发审批，根据工具目标决定是否允许。

## 5. 再尝试一个小修改

确认只读过程符合预期后，再给出边界明确的修改任务：

```text
给现有的 camel_to_snake 函数补空字符串和连续大写字母测试。
只修改测试文件，并运行最小测试集。
```

结束后检查：

- 实际修改了哪些文件。
- 测试命令、范围和退出结果。
- 哪些检查没有运行。
- 工作区 diff 是否符合任务边界。

## 6. 记住几个 TUI 入口

| 想做的事 | 在输入区键入 |
| --- | --- |
| 管理 Provider | `/login` |
| 选择模型与档位 | `/model` |
| 浏览历史会话 | `/threads` |
| 查看服务状态 | `/status` |
| 查看 MCP 状态 | `/mcp` |

面板内通常使用方向键移动、Enter 进入或确认、Esc 返回。不要依赖尚未接线的 Ctrl 面板快捷键。
