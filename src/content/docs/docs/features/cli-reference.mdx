这份参考以当前代码调用路径为准。`peri --help` 能证明参数可被解析，但不能证明参数已经接入运行时；下文因此把参数分成“已接线”和“已解析但未生效”两类。

## 已接线的基础入口

| 命令 | 当前行为 |
| --- | --- |
| `peri` | 启动交互式 TUI。没有显式权限参数时，初始权限模式是 Bypass |
| `peri -a` | 启动 TUI，并把初始权限模式设为 Default |
| `peri --permission-mode <mode>` | 设置初始权限模式：`bypass`、`default`、`accept-edit` 或 `auto-mode` |
| `peri -c` | 在 TUI 中加载当前目录最近的会话（如果存在） |
| `peri -r <session_id>` | 在 TUI 中加载指定会话；请传入实际 UUID |
| `peri --config-file <path>` | 重定向全局 settings 文件路径 |
| `peri --db-path <path>` | 重定向 SQLite 会话数据库路径 |
| `peri update` | 下载并执行仓库 `main` 分支上的安装脚本 |

`--dangerously-skip-permissions` 也会选择 Bypass。权限模式只控制工具审批，不提供容器、文件系统或网络隔离。安全边界见[权限系统](/peri-cool/docs/features/permissions/)。

## 非交互模式

```bash
peri -p "解释 src/main.rs"
echo "解释 src/main.rs" | peri -p
```

`-p` 创建一次临时 ACP 会话，输出响应后退出。它当前默认使用 Bypass，并自动接受运行期间出现的权限请求，因此不要把它直接用于未隔离的 CI 环境。

已接线选项：

| 参数 | 当前行为 |
| --- | --- |
| `--output-format text` | 只输出最终文本；默认值 |
| `--output-format json` | 最终输出一个 JSON result |
| `--output-format stream-json` | 逐行输出文本和工具事件 JSON |
| `--model <alias>` | 尝试按配置中的档位选择 provider 和模型；找不到该档位时沿用当前 provider |
| `--settings <path-or-json>` | 从指定文件或 JSON 字符串加载本次运行的配置 |
| `--bare` | 跳过 settings hooks、LSP 和插件等装配 |
| `--db-path <path>` | 使用指定会话数据库；打开失败时退出 |

<Aside type="caution">
  <code>-p</code> 不是“只推理一轮”的同义词。当前 <code>--max-turns</code> 虽然出现在帮助中，但没有接入执行循环。
</Aside>

## 已解析但尚未生效

以下参数目前会被命令行解析器接受，但调用路径没有应用其值。不要依赖它们做安全限制或资源控制。

| 参数 | 受影响入口 | 当前状态 |
| --- | --- | --- |
| `--max-turns` | `-p` | 未限制 Agent 轮数 |
| `--effort` | TUI、`-p` | 未覆盖实际请求的 effort |
| `--allowedTools` / `--allowed-tools` | TUI、`-p` | 未限制可用工具 |
| `--disallowedTools` / `--disallowed-tools` | TUI、`-p` | 未禁用工具 |
| `--no-session-persistence` | CLI | 解析后未传入运行路径 |
| `--model` | TUI | 会解析并查找配置，但没有替换 TUI 实际使用的 provider；`-p` 路径已接线 |
| `--session-id`、`--name` | TUI | 解析后未用于创建会话 |
| `peri acp --model`、`peri acp --agent` | ACP stdio | 子命令接受参数，但启动时忽略 |

这些参数仍可能随产品实现变化。判断当前版本时，以这里的说明和实际调用路径为准，而不是只看 `--help`。

## 插件与其他子命令

插件 CLI 提供 `list`、`install`、`uninstall`、`enable`、`disable`、`update`、`info`、`search`、`cleanup` 和 `marketplace` 管理入口。安装一次只接受一个插件标识：

```bash
peri plugin install frontend-design@claude-plugins-official
```

另有 `peri sync ...`、`peri web ...` 与 `peri acp ...`。各子命令的参数以对应的 `--help` 为入口；其中 `peri web` 默认监听 `0.0.0.0`，启动前应确认网络暴露范围。

## TUI 本地命令

这些命令由 TUI 直接处理，不交给 Agent：

| 命令 | 行为 |
| --- | --- |
| `/setup` | 打开或关闭首次配置向导 |
| `/provider` | 循环切换 Provider |
| `/mode` | 循环切换权限模式 |
| `/clear`、`/cls`、`/reset` | 清空当前会话 |
| `/rewind [message_id] [--revert-files]`、`/undo` | 打开回退界面或回退到指定消息；是否回退文件需显式选择 |
| `/debug-export-text [screen]` | 导出全部会话文本，或只导出当前屏幕 |
| `/exit`、`/quit` | 退出 TUI |

`/compact` 等未被本地 parser 识别的斜杠文本会发送给 Agent，由当前会话的 skill、命令或工具能力解释；它不是本地硬编码命令。

## 面板命令

当前面板入口包括 `/model`、`/login`、`/agent`、`/hooks`、`/config`、`/threads`、`/mcp`、`/plugin`、`/cron`、`/status`、`/memory`、`/tasks`、`/betas`、`/workflows` 和 `/theme`。`/history`、`/resume`、`/his` 是 `/threads` 的别名。

面板命令后的额外参数不会传给面板。快捷键与面板操作见 TUI 导航页；功能边界以各专题文档为准。
