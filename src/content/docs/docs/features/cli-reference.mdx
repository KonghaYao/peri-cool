本文档是 Peri 所有命令的速查手册——CLI 参数和斜杠命令两种形态。

## CLI 参数

在终端中直接使用的命令行参数。

### 基础参数

| 命令 | 说明 | 示例 |
|------|------|------|
| `peri` | 启动交互式 TUI | `peri` |
| `peri --version` | 查看版本号 | `peri --version` |
| `peri --help` | 查看帮助信息 | `peri --help` |

### 单次对话

| 命令 | 说明 | 示例 |
|------|------|------|
| `peri -p "<prompt>"` | 非交互式单次对话 | `peri -p "用 Rust 写一个快速排序"` |
| `peri -p "<prompt>" --max-turns 1` | 单次对话，只执行一轮 | `peri -p "解释 src/main.rs" --max-turns 1` |
| `peri -p "<prompt>" --model <name>` | 单次对话使用指定模型 | `peri -p "审查代码" --model deepseek-v3` |

<Aside type="note">
  <code>-p</code> 模式下 Peri 完成任务后自动退出，不会进入交互式 TUI。
</Aside>

### 模型与会话

| 命令 | 说明 | 示例 |
|------|------|------|
| `peri --model <name>` | 启动时指定默认模型 | `peri --model claude-sonnet` |
| `peri -c` / `peri --continue` | 恢复当前目录最近的会话 | `peri -c` |
| `peri -r <session_id>` / `peri --resume <session_id>` | 恢复指定会话 | `peri --resume abc123` |

<Aside type="note">
  历史会话可在 TUI 内用 <code>/threads</code> 面板浏览；<code>--resume</code> 只接受具体会话 ID，<code>--resume last</code> 无效。
</Aside>

### 配置管理

Peri 没有 `config` 子命令。配置文件位于 `~/.peri/settings.json`（JSON 格式，顶层结构为 `{"config": {...}}`），可在 TUI 中用 `/config` 面板（快捷键 `Ctrl+F`）查看和编辑。

### 更新

| 命令 | 说明 | 示例 |
|------|------|------|
| `peri update` | 从 GitHub 下载并安装最新版本 | `peri update` |

## 斜杠命令

在 Peri TUI 中，以 `/` 开头输入。以下为完整列表。

### 控制

本地控制命令不经过 Agent，立即生效：

| 命令 | 说明 | 示例 |
|------|------|------|
| `/setup` | 打开或关闭 Setup 向导 | `/setup` |
| `/provider` | 循环切换 Provider | `/provider` |
| `/mode` | 循环切换权限模式（快捷键 `Shift+Tab`） | `/mode` |
| `/debug-export-text [screen]` | 导出当前会话文本，`screen` 只导出当前屏幕 | `/debug-export-text screen` |
| `/exit`、`/quit` | 退出 TUI | `/exit` |
| `/bg <任务描述>` | 立即命令：fork 当前会话启动后台子 Agent 执行独立任务 | `/bg 修复 lint 错误` |

### 会话

| 命令 | 说明 | 示例 |
|------|------|------|
| `/clear`、`/cls`、`/reset` | 清空当前会话的所有对话历史（三者等价） | `/clear` |
| `/rewind`（别名 `/undo`） | 回滚对话到指定消息，可带 `--revert-files`；无参时进入 Rewind 弹窗（双击 `Esc` 同） | `/rewind <target_message_id>` |
| `/compact` | 立即命令：用 LLM 生成结构化摘要并保留关键文件内容，释放 token | `/compact` |

### 面板

| 命令 | 说明 | 示例 |
|------|------|------|
| `/model` | 打开 Model 面板（参数被忽略） | `/model` |
| `/theme` | 打开 Theme 面板（参数被忽略） | `/theme` |
| `/config` | 打开 Config 面板，编辑 `~/.peri/settings.json`（快捷键 `Ctrl+F`） | `/config` |
| `/agent` | 打开 Agent 面板，管理子代理定义 | `/agent` |
| `/hooks` | 打开 Hooks 面板，查看 hook 事件 | `/hooks` |
| `/threads`（别名 `/history`、`/resume`、`/his`） | 打开 Threads 面板，浏览历史会话 | `/threads` |
| `/mcp` | 打开 MCP 面板，管理 MCP 服务器池 | `/mcp` |
| `/plugin` | 打开 Plugin 面板，管理已安装插件 | `/plugin` |
| `/cron` | 打开 Cron 面板，管理定时任务 | `/cron` |
| `/status` | 打开 Status 面板，查看服务快照 | `/status` |
| `/memory` | 打开 Memory 面板，查看持久化记忆 | `/memory` |
| `/tasks` | 打开 Tasks 面板，查看后台任务 | `/tasks` |
| `/betas` | 打开 Betas 面板，切换功能开关 | `/betas` |
| `/workflows` | 打开 Workflows 面板，查看工作流运行 | `/workflows` |
| `/login` | 打开 Login 面板，配置 Provider 凭据 | `/login` |

<Aside type="tip">
  日常换模型不用敲命令：**鼠标点击状态栏中间模型段**（`档位 · 模型 · effort`）弹出快速切换弹窗，或按 `Ctrl+M` 打开 Model 面板编辑四个档位的完整配置。见 [模型档位](/peri-cool/docs/features/model-profiles/)。
</Aside>

权限模式通过 `/mode` 循环切换（快捷键 `Shift+Tab`），详细说明见 [权限管理](/peri-cool/docs/features/permissions/)。
