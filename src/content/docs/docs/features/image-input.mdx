## 是什么

Peri 支持把图片作为消息发给模型——不只是传文件路径，而是真正把图片内容交给模型"看"。

典型场景：

- 界面报错：截图后直接粘贴，不用手打错误信息
- 设计稿还原：把 Figma 截图贴进去，让 Peri 照着写
- 图表数据：把表格截图贴进去，让 Peri 提取数据

## 怎么用

在输入框直接 `Ctrl+V`（macOS 为 `Cmd+V`）粘贴剪贴板里的图片：

```text
你: [Cmd+V 粘贴截图]
    [输入框出现 @image /Users/you/.peri/images/xxxx.png]

你: 这个报错窗口是什么意思？怎么修？
```

Peri 会把图片存到 `~/.peri/images/`，然后以图片消息发给模型。粘贴多张图片就多插几个 `@image`，一次可以发多张。

<Aside type="note">
  终端里拖拽文件会自动在输入框插入文件路径，这个场景不需要额外操作——图片文件也一样。
</Aside>

## @image 语法

`@image` 也可以手动输入，直接引用磁盘上的图片文件：

```text
@image ~/screenshots/bug.png 帮我分析这个界面哪里不对
```

规则：

- 语法 `@image <路径>`，路径到行尾
- 支持 `~` 展开和相对路径
- 一条消息里可以有多个 `@image`

## 边界情况

| 情况 | 行为 |
|------|------|
| 路径不存在 | 替换为 `[Image not found: /path]` 文本，不中断对话 |
| 文件不是图片 | 替换为 `[Not an image: /path]` |
| 文件超过 20MB | 替换为 `[Image too large: XMB > 20MB limit]` |
| 模型不支持视觉 | 图片会以 `[Image: ...]` 占位形式进入上下文，需要换多模态模型 |

## 限制

- 图片大小上限 20MB
- 只处理最新一条用户消息中的 `@image`
- 需要模型本身支持图片输入（Claude 和 OpenAI 系多模态模型都可以；纯文本模型会收到占位符）
- 目前没有压缩/缩放管线——超大图片直接发原图，注意 token 消耗

<Aside type="tip">
  图片在对话历史里按 `[Image: ...]` 占位保存，不会让后续每一轮都重复携带图片——compact 之后也一样。
</Aside>
