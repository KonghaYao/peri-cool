Skill 是 Peri 的专项能力模块。每个 skill 定义了一种专门的行为模式——比如写博客、诊断 bug、做实验——Peri 在需要时自动加载。

## 怎么用

Skills 放在了 `.claude/skills/` 目录下，Peri 启动时自动扫描。兼容 Claude Code 的 skill 格式。

<FileTree>
- .claude/
  - skills/
    - diagnosing-bugs/
      - SKILL.md
    - blog-writer/
      - SKILL.md
    - code-review/
      - SKILL.md
</FileTree>

每个 skill 的 `SKILL.md` 定义了触发条件和行为规则。Peri 根据对话内容自动匹配需要加载哪个 skill。

<Aside type="tip">
  Peri 内置（builtin）skill 只有 4 个：cron、goal、ultracode、use-artifacts，编译在 peri-middlewares 中。其余 skill 来自用户级（~/.claude/skills/）、全局（~/.peri/settings.json 的 skillsDir）、项目级（.claude/skills/）和插件级。同名 skill 按优先级覆盖——用户级 > 全局 > 项目级 > 插件级 > 内置。
</Aside>

## 触发方式

Peri 没有 `/skill-name` 斜杠命令解析——输入 `/xxx` 会作为普通文本发给 agent。实际触发方式是：

1. **自动匹配**：Peri 启动时将扫描到的所有 skill 的 name + description 摘要注入系统提示词，分析你的需求后自动加载最匹配的 skill。
2. **直接描述**：输入技能名或描述任务（如"用 ultracode 编排并行工作流"、"每 5 分钟跑一次"），Peri 按需加载。消息中的 `/skill-name` 模式会被 SkillPreloadMiddleware 识别并预加载对应 skill 全文；内置 skill 的 SKILL.md 都声明了 `userInvocable: true`，被直接提及即可触发。

## 内置 Skills

Peri 内置 skill 共 4 个：

| Skill | 触发场景 |
|-------|---------|
| **cron** | 定时任务、周期性提醒（标准 5 字段 cron 表达式） |
| **goal** | 长任务目标跟踪，多轮持续推进直到完成 |
| **ultracode** | 并行/流水线多 agent 工作流编排 |
| **use-artifacts** | 制品（artifact）工具的使用时机与调用流程 |

## 自定义 Skill

Skill 就是一个 Markdown 文件。格式很简单：

```markdown
---
name: my-skill
description: 触发这个 skill 的场景描述。
---

# 你的 skill 内容
这里是具体的规则和指令。
```

放在 `.claude/skills/my-skill/SKILL.md`，Peri 下次启动自动加载。
