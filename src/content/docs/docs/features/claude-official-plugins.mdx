Peri 可以读取 Claude Code 风格的 marketplace 和插件清单。`anthropics/claude-plugins-official` 是可添加的 marketplace 来源；其中实际有哪些插件、版本和能力会随上游仓库变化，应以本地 marketplace 清单为准。

## 添加 marketplace

```bash
peri plugin marketplace add anthropics/claude-plugins-official
peri plugin marketplace list
```

添加操作会获取 marketplace 并保存本地注册信息。如果名称已经存在且缓存有效，命令会跳过重复添加。

## 一次安装一个插件

`peri plugin install` 每次只接受一个位置参数。推荐写完整的 `name@marketplace`：

```bash
peri plugin install skill-creator@claude-plugins-official
peri plugin install frontend-design@claude-plugins-official
peri plugin install claude-md-management@claude-plugins-official
```

不要把多个名称放在同一条 `install` 命令中。未写 `@marketplace` 时，Peri 会搜索已注册 marketplace；如果同名或来源不明确，显式写完整 ID 更容易排障。

安装范围默认为 `user`，也可以逐次指定：

```bash
peri plugin install frontend-design@claude-plugins-official --scope project
peri plugin install frontend-design@claude-plugins-official --scope local
```

可用 scope 为 `user`、`project` 和 `local`。

## 查看与维护

```bash
peri plugin list
peri plugin info frontend-design@claude-plugins-official
peri plugin disable frontend-design@claude-plugins-official
peri plugin enable frontend-design@claude-plugins-official
peri plugin update frontend-design@claude-plugins-official
peri plugin uninstall frontend-design@claude-plugins-official
```

`/plugin` 面板用于查看和操作本地插件状态。插件可贡献 skills、agents、hooks 和 MCP 配置；实际贡献项取决于该版本的 manifest，不能从插件名称推断。

## 使用插件能力

安装并启用后，直接用任务语言描述需求。例如：

```text
创建一个用于发布前检查的 skill，并给它设计几个评测场景。
```

```text
审计这个仓库的 CLAUDE.md，找出过时规则和缺失的验证命令。
```

```text
重新设计这个设置页面，保留现有交互与数据流。
```

Agent 会根据当前已加载的 skill 描述决定是否使用对应能力。具体触发名称和流程以安装版本的 `SKILL.md` 为准。

<Aside type="caution">
  插件是本地可执行能力的一部分。安装前检查来源和 manifest；插件提供的 hook、MCP server 或命令可能执行外部程序、访问网络或读取项目文件。
</Aside>

遇到“找不到插件”时，先运行 marketplace update，再用 plugin search 或 marketplace 缓存确认准确名称。安装完成但能力未出现时，确认插件已启用并重启 Peri，让会话重新装配插件数据。
