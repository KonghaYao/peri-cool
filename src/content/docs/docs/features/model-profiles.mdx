## 是什么

Peri 内置四个固定的模型档位（Profile）：

| 档位 | 定位 | 默认 effort | 默认 max_tokens |
|------|------|------------|-----------------|
| `fable` | 最强推理（复用 opus 档的模型映射） | xhigh | 32000 |
| `opus` | 深度推理、复杂架构 | xhigh | 32000 |
| `sonnet` | 日常编码主力 | xhigh | 32000 |
| `haiku` | 探索、搜索、轻量任务 | xhigh | 32000 |

每一档都**独立**持有自己的 `provider`、`model`、`effort`、`max_tokens`、`context_1m`。切换档位时整组配置一起生效——不用每次重新设模型和推理强度。

<Aside type="note">
  档位固定四个，不能增删改名。每档的模型名、effort 等可以随意配置；`max_tokens` 只能在预设档位 `4096 / 8192 / 16000 / 32000 / 64000` 间循环选择。
</Aside>

## 怎么用

### 快速切换：点击状态栏模型段

状态栏中间显示 `档位 · 模型 · effort` 三段，例如 `sonnet · claude-sonnet-4-5 · xhigh`：

```text
Don't Ask · repo-name · sonnet · claude-sonnet-4-5 · xhigh · MEM 1568MB
```

**鼠标左键点击模型段**，弹出档位快速切换弹窗，上下选择回车确认。档位名与模型名相同时只显示一次。

### 完整编辑：Model 面板

输入 `/model` 打开 Model 面板，左右分栏：

```text
┌─ Model ─────────────────────────────────────────────────────┐
│ Model                                                       │
│ ───────────────────────       ────────────────────────────  │
│ ● fable · anthropic           Provider     anthropic        │
│   claude-opus-4-6             Model        claude-sonnet-4-5│
│   xhigh · 200k                Effort       xhigh            │
│                               Max tokens   32000            │
│ ○ opus · anthropic            1m enable    off              │
│   claude-opus-4-6                                             │
│   xhigh · 200k                                                │
│                                                              │
│ ○ sonnet · anthropic                                         │
│   claude-sonnet-4-5                                          │
│   xhigh · 200k                                               │
│ ↑/↓ 切换  Tab 左右  ←/→ 改值  Esc 退出/关闭                  │
└──────────────────────────────────────────────────────────────┘
```

- 左侧：四个档位卡片，↑/↓ 选择即切换；**鼠标左键点击卡片行同样生效**（click as enter）
- 右侧：当前档位的 K/V 编辑行，`Tab` 在左右焦点间切换，`←/→` 修改值，`esc` 关闭

### 改值即保存，切换即生效

Model 面板没有"保存"按钮——**改值立即生效**：

- 右侧 `←/→` 修改任一字段，同时写入配置内存、持久化到 `settings.json`、推送给后端，下一次请求就用新参数，无需重启
- 切换档位（键盘或鼠标）后，**状态栏模型段闪烁约 2 秒**提示变更生效
- 面板里看到的 `active alias` 与状态栏共用同一份状态，两边永远一致

## 模型解析顺序

某一档实际使用的模型，按这个优先级决定：

1. 该档 `model` 手动指定了模型名 → 用它
2. 否则用该档 `provider` 的 `models` 映射里同档位的模型（`fable` 为空时回退 `opus`）
3. 否则用档位名本身

provider 同理：该档 `provider` 为空时回退到第一个可用 provider。

## 配置文件

档位配置存在 `~/.peri/settings.json`（JSON 格式；项目目录下的 `.peri/settings.json` 可以覆盖）：

```json
{
  "config": {
    "active_alias": "sonnet",
    "profiles": {
      "fable": {
        "provider": "anthropic",
        "effort": "xhigh",
        "max_tokens": 32000
      },
      "opus": {
        "provider": "anthropic",
        "model": "claude-opus-4-6",
        "effort": "max",
        "max_tokens": 64000
      },
      "sonnet": {
        "provider": "openai",
        "model": "gpt-5.6-luna",
        "effort": "high",
        "context_1m": true
      },
      "haiku": {
        "provider": "anthropic",
        "effort": "low",
        "max_tokens": 8192
      }
    }
  }
}
```

### effort 可选值

| 值 | 含义 |
|----|------|
| `low` / `medium` | 快速响应，省钱 |
| `high` / `xhigh` | 深度思考，默认 `xhigh` |
| `max` | 推理拉满 |

### 项目级覆盖

项目级配置按**档位整体替换**：项目里写了 `profiles.sonnet`，就用项目级的完整档位，不再和全局做字段级合并。项目级不能新增档位——只有固定四档。

边界情况：项目级档位恰好等于默认值（`provider` 为空、`model` 未设置、`effort` 为 `"xhigh"`、`max_tokens` 为 `32000`、`context_1m` 为 `false`）时视为**未覆盖**，该档位保留全局配置。

<Aside type="tip">
  省钱的正确姿势：`haiku` 档配便宜模型 + `low` effort，日常探索用它；写代码切 `sonnet`，架构设计切 `opus`。改配置在 Model 面板里点几下就行。
</Aside>
